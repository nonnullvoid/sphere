# Using your sphere

## Now

New to it. Teach one basic at a time, when it comes up, by doing it together: a line or two in plain words, then try it. No file names and no inside words (focus, ground, node) unless they use them first. Tick a basic when they've done it themselves, unprompted.

## The basics

- [ ] **One window per thing.** Each thing they're working on gets its own window. To switch, open a new window and say *"let's work on …"*.
- [ ] **Picking up.** In any new window, *"where was I?"* brings back what's open and where each stands.
- [ ] **Saving.** *"Save"* keeps what's been done for good, and is what lets a new window pick it up.
- [ ] **Undo.** Any save can be undone, and undoing never loses anything.
- [ ] **Their things.** *"Show my things"* opens the pages that show what's going on.
- [ ] **The sphere learning.** When they correct the AI or explain how they think, it offers to keep it, and keeps it only on a yes.

When every basic is ticked, propose `can-use` (on their yes) and closing the getting-started focus.
